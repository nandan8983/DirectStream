# DirectStream v0.01 (TV Receiver & Mobile Controller)

## How to Build the APK

### Option 1: Local Windows Build
1. Ensure Flutter SDK is installed on your machine.
2. Double-click `build_apk.bat`.
3. Your installable APK will be generated at `build/app/outputs/flutter-apk/app-debug.apk`.

### Option 2: Free Cloud Build via GitHub Actions
1. Upload these files to a GitHub repository.
2. Open the **Actions** tab on GitHub.
3. Download the compiled `DirectStream-v0.01-apk` artifact once the workflow completes.
